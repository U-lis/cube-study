### T3-1. 기준 상세 화면 진도 표시 초기값 (FR-MC-10)

| # | 단계 | 완료 조건 |
|---|------|----------|
| 1 | localStorage를 초기화한 상태에서 `/anchors/[code]` 접속 | 진도 표시 요소가 `0/{전체 케이스 수}` 형식으로 표시된다 |
| 2 | 전체 케이스 수 확인 | 데이터의 해당 기준 케이스 수와 일치한다 |
| 3 | 진도바 또는 퍼센트 요소 | 존재하지 않는다 |
| 4 | "N개 남았어요", "다 외웠어요" 등의 문구 | 존재하지 않는다 |

### T3-2. 기준 상세 화면 진도 숫자 — 체크 반영 (FR-MC-10, 12)

| # | 단계 | 완료 조건 |
|---|------|----------|
| 1 | 케이스 행 체크박스 1개 체크 | 진도 좌측 숫자가 `0` → `1`로 바뀐다 |
| 2 | 추가로 체크박스 1개 더 체크 | 진도 좌측 숫자가 `2`로 바뀐다 |
| 3 | 체크박스 해제 | 진도 좌측 숫자가 `1`로 줄어든다 |
| 4 | 새로고침 | 진도 숫자가 유지된다 (localStorage 영속화) |

### T3-3. direct 체크가 setup 진도에 영향 없음 (FR-MC-1, 10)

| # | 단계 | 완료 조건 |
|---|------|----------|
| 1 | `addInitScript`로 `checked.direct = ["LB", "SC"]` (임의 케이스), `checked.setup = []` 주입 | `/anchors/[code]` 진도 좌측이 `0`이다 |
| 2 | 조회 화면에서 `mode = 'direct'`로 케이스를 체크 | `/anchors/[code]`의 진도 숫자가 변하지 않는다 |

### T3-4. 기준공식 목록 화면 진도 표시 (FR-MC-11)

| # | 단계 | 완료 조건 |
|---|------|----------|
| 1 | localStorage 초기화 상태에서 `/anchors` 접속 | 모든 기준 카드에 `0/{카드별 전체 케이스 수}` 형식이 존재한다 |
| 2 | 전체 케이스 수 합계 확인 | `Dataset.cases` 전체 케이스 수(378)와 일치한다 |
| 3 | 체크가 0개인 기준 카드 | `0/{전체}`로 표시. 항목이 숨겨지거나 별도 분류되지 않는다 |

### T3-5. 기준공식 목록 — 체크 후 진도 갱신 (FR-MC-11)
