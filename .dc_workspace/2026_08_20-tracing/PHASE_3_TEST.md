# Phase 3 — 테스트 계획

## 테스트 커버리지 목표

E2E 중심. 화면 상태 기계와 계시 규칙이 대상이다.

## 실행 명령

```bash
pnpm test:e2e tests/e2e/trace-session.spec.ts
pnpm test                 # e2e-tags 규약 검사 포함
pnpm build
```

E2E 는 `http://localhost:4174` 로 돈다 (`playwright.config.ts`). LAN IP 를 쓰지 않는다.

## E2E (`tests/e2e/trace-session.spec.ts`)

워커 초기화가 1.7초라 `ready` 대기는 명시적 `expect(...).toBeEnabled({ timeout })` 로 기다린다.
고정 `waitForTimeout` 을 쓰지 않는다.

### T3-1. 회색 시작 (FR-TR-22)

| # | 단계 | 완료 조건 |
|---|---|---|
| 1 | `/trace` 진입 | 캔버스가 존재하고 상태가 `idle` |
| 2 | 시작 전 DOM | 스크램블 문자열이 DOM 어디에도 없다 |
| 3 | 시작 전 캔버스 | 픽셀 표본이 전부 회색 계열 (스크린샷 표본 검사) |
| 4 | 회색 상태에서 드래그 | 캔버스 픽셀이 바뀐다 (회전 가능) |
| 5 | 시작 클릭 | 캔버스에 회색 아닌 색이 나타난다 |
| 6 | 시작 직후 타이머 | `0.00` 에서 증가한다 |

### T3-4. 세션 설정 (FR-TR-19, 24)

| # | 단계 | 완료 조건 |
|---|---|---|
| 1 | 대상 = 엣지 선택 후 새로고침 | 선택이 복원된다 (`trace.pieceKind`) |

### T3-6. 워커 반납 (NFR-TR-1)

| # | 단계 | 완료 조건 |
|---|---|---|
| 1 | `/trace` → `/quiz` 이동 | `dispose()` 가 불려 워커가 종료된다 (관측 가능한 신호로 확인) |

### T3-7. 레이아웃 (`@viewport`)

| # | 단계 | 완료 조건 |
|---|---|---|
| 1 | 모바일 폭에서 `/trace` | 가로 스크롤이 생기지 않는다 |
| 2 | 하이드레이션 전후 캔버스 자리 | `boundingBox` 가 같다 (레이아웃 점프 없음) |
| 3 | 타이머 숫자가 커질 때 | 주변 요소가 밀리지 않는다 (`tabular-nums` + `min-width`) |
| 4 | 버튼 터치 타깃 | 44px 이상 |

**이 절은 `@viewport` 태그가 필수다.** 태그가 없으면 mobile 프로젝트에서 조용히 빠진다
(`playwright.config.ts` 주석, `tests/unit/e2e-tags.test.ts`).
