# Phase 4 — 테스트 계획

## 테스트 커버리지 목표

E2E 중심. 채점 자체는 Phase 1A 의 단위 테스트가 이미 전수 검증했으므로, 여기서는 **화면이 엔진 결과를
그대로 옮기는가** 를 본다.

## 실행 명령

```bash
pnpm test:e2e tests/e2e/trace-input.spec.ts
pnpm test
pnpm build
```

데이터·정답이 필요한 테스트는 `tests/e2e/quiz.spec.ts:11-15` 방식으로 `loadDataset()` 을 불러 값을 얻는다.
타깃 문자를 리터럴로 박지 않는다.

**결정적 스크램블 확보**: 무작위 스크램블로는 기대 정답을 미리 알 수 없다. `addInitScript` 로 스크램블
소스를 고정 값으로 주입하거나(테스트 훅), 화면이 노출한 상태에서 `trace()` 를 테스트 쪽에서 계산해
기대값을 만든다. 두 방법 중 하나를 골라 스펙 상단 주석에 근거를 적는다.
