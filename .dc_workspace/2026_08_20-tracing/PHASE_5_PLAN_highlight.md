# Phase 5 — 하이라이트와 누출 방지 (highlight)

**담당**: FR-TR-15, 16
**의존**: Phase 4 완료
**병렬 불가**: `/trace/+page.svelte` 와 `Cube3D.svelte` 를 함께 고친다

## 목표

이 페이즈가 끝나면:
- 버퍼 / 현재 타깃 / 이미 지나간 조각이 3D 큐브에 **동시에 서로 다른 색** 으로 칠해진다
- 하이라이트가 색과 테두리로 이중 부호화된다
- 뒷면 정보가 회전 없이 새어나가지 않는다는 것이 E2E 로 못 박힌다
- 0.5.0 의 기능이 전부 완성된다

## 선행 조건

- Phase 4 완료

## 대응 SPEC

| FR | 내용 |
|---|---|
| FR-TR-15 | 뒷면이 회전 없이 새어나가면 안 된다. 힌트·반투명·미니맵·전개도 보조 금지 |
| FR-TR-16 | 버퍼 / 현재 타깃 / 지나간 조각을 동시에 다른 색으로. 지나간 조각은 계속 늘어난다. 색만으로 구분하지 않는다 |

## 무엇을 칠하는가

뷰어는 "무슨 색을 어디에" 만 받는다 (GLOBAL AD-12). 무엇을 칠할지는 화면이 정한다.

| 대상 | 언제 | 표시 |
|---|---|---|
| 버퍼 | 항상 (`tracing` 단계) | 색 A + 테두리(굵은 실선) |
| 현재 타깃 | `follow` 모드에서 마지막으로 입력한 문자 | 색 B + 테두리(이중선) |
| 지나간 조각 | 입력한 문자 전부 (마지막 제외) | 색 C + 테두리(점선) |
| 나머지 | | 하이라이트 없음 |

- 지나간 조각은 **개수 상한이 없다** — 코너 평균 8 + 엣지 평균 12 이고 끊기가 늘면 더 는다
- `memorize` 모드의 입력 단계에는 큐브가 없다. 하이라이트도 없다 (FR-TR-21)
- 결과 화면에서는 정답 예시 경로를 같은 방식으로 칠할 수 있다 — 다만 **훈련 중에는 칠하지 않는다**
  (힌트가 된다, FR-TR-15)

전 면 회색(FR-TR-22)도 같은 경로다. 뷰어 API 는 하나뿐이다.

## 수정할 파일

### `src/routes/trace/+page.svelte` (수정)

입력 상태에서 54칸 `marks` 배열을 만든다.

```ts
const marks = $derived(buildMarks(pieceKind, meta, entered));
```

`buildMarks` 는 `src/lib/domain/tracing.ts` 에 **순수 함수** 로 둔다 — 화면에서 배열을 조립하면 단위
테스트가 안 된다.

```ts
export function buildMarks(
  kind: PieceKind,
  meta: DatasetMeta,
  entered: Sticker[],
  palette: MarkPalette
): (Mark | null)[]
```

문자 → facelet 인덱스는 `CORNER_INDEX`/`EDGE_INDEX`(`speffz.ts:23-38`)로 얻는다. 버퍼 스티커는
`meta.bufferStickers` 에서 온다 — 리터럴 금지 (FR-TR-7).

**조각 하나를 칠할 때 그 조각의 스티커를 전부 칠한다.** 코너면 3칸, 엣지면 2칸이다. 한 칸만 칠하면
돌렸을 때 조각을 놓친다.

색은 `meta.colorScheme` 의 스티커 색과 **구분되는** 값이어야 한다. 팔레트를 화면이 정하고 뷰어에 넘긴다.

### `src/lib/ui/Cube3D.svelte` (수정)

`marks` prop 을 받아 `setHighlights` 로 전달. 컴포넌트가 하는 일은 전달뿐이다.

### `tests/e2e/trace-noleak.spec.ts` (신규)

FR-TR-15 를 못 박는 테스트다. **이 테스트가 이 페이즈의 본론이다** — 하이라이트를 넣다 보면 "조금만
보여주면 편한데" 가 반드시 나온다.

## 이 페이즈에서 조심할 것

| 위험 | 대응 |
|---|---|
| "조금만 보여주면 편한데" | FR-TR-15 정면 위반. E2E 로 못 박는다. 훈련하려는 기술이 사라진다 |
| 색만으로 3종 구분 | 테두리 종류를 함께 쓴다. 색약 고대비 모드는 별도 이슈지만 이중 부호화는 지금 한다 |
| 하이라이트 개수 상한 | 지나간 조각은 계속 는다. 상한을 두지 않는다 |
| 조각의 한 칸만 칠함 | 돌리면 조각을 놓친다. 스티커 전부 칠한다 |
| 배열 조립을 화면에서 함 | `buildMarks` 를 순수 함수로 빼서 단위 테스트한다 |
| 스크램블이 DOM 으로 샘 | 색은 캔버스에만. 문자열을 `data-*` 나 텍스트로 남기지 않는다 |
| 힌트 기능 추가 | Out of Scope. SPEC 이 명시적으로 뺐다 |
