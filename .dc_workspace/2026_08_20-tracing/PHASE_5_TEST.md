## E2E (`tests/e2e/trace-noleak.spec.ts`)

### T5-2. 뒷면 누출 금지 (FR-TR-15)

| # | 단계 | 완료 조건 |
|---|---|---|
| 1 | 세션 시작 직후 캔버스 스크린샷 | 보이는 면이 3개 이하 (코너 시점) |
| 2 | 캔버스 픽셀 표본 | 뒷면 색이 앞면 위로 비쳐 보이지 않는다 (반투명 없음) |
| 3 | DOM 전체 텍스트 | 스크램블 문자열이 없다 |
| 4 | DOM 속성 | facelet 배열·색 배열이 `data-*` 에 없다 |
| 5 | 페이지 HTML | `미니맵`·전개도·힌트에 해당하는 요소가 없다 |
| 6 | 드래그로 180° 회전 | 그때 처음 뒷면 색이 보인다 |
| 7 | 훈련 중 결과 예시 | 정답 경로가 칠해지지 않는다 |
| 8 | `memorize` 모드에서 "다 외웠다" 이후 | 캔버스가 없고 색 정보도 DOM 에 없다 |

**#3~#5 가 이 페이즈의 핵심이다.** 캔버스는 회전해야 보이지만 DOM 은 개발자 도구로 그냥 보인다.
